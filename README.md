## 为什么叫变色龙

变色龙会随环境改变颜色，把自己藏进背景里，让天敌看不出来。

Chameleon 做的是同一件事：它没有窗口边框、没有底色、没有阴影、不进任务栏，屏幕上只画出文字，直接贴在你的桌面和其它程序之上。你看它的时候它在，鼠标一移开它就消失，鼠标事件直接穿透到下层程序——**屏幕上和平时没有任何区别**。

## 上班摸鱼怎么用

1. 把要看的资料（Markdown 文件）放进一个文件夹；
2. 把文件夹或单个 `.md` 文件**拖到 `Chameleon.exe` 上**（不用先启动程序）；
3. 鼠标停在屏幕角落 → 资料淡入 → 滚两行 → 鼠标移开 → 屏幕立刻恢复原样；
4. 需要时按 `Alt + Shift + Q` 全局唤出 / 隐藏，连鼠标都不用找。

适合这些时刻：等编译、等构建、开会时对参数、背后有人走来走去、想瞄一眼文档又不想多开一个窗口。

## 和普通 Markdown 阅读器的区别

| | 普通阅读器 | Chameleon |
| --- | --- | --- |
| 外观 | 标题栏、底色、阴影 | 只剩文字，无边框、无底色 |
| 显隐 | 手动关闭或最小化 | 鼠标静止才出现，移开即隐去 |
| 干扰 | 占任务栏、盖住下层 | 不占任务栏，隐去后鼠标事件穿透 |
| 安全性 | 通常可编辑 | 纯只读，机制上无法改文件 |
| 安装 | 安装包 | 解压即用，可放 U 盘 |

## ✨ 特性

- **零底色悬浮窗**：无边框、无底色、无阴影、无轮廓，界面只绘制文字。下层是纯色、渐变、图片还是代码编辑器都无需适配。
- **静止才显现**：鼠标在窗口内完全静止后淡入，**默认 0.6 秒，可在设置窗口里改成 250 ~ 2000 毫秒**；只是掠过或仍在移动时不会显示，鼠标经过不会暴露窗口。
- **移开即隐去**：鼠标移出窗口（带 16px 滞回，避免边缘抖动）后淡出至完全不可见，**淡出时长默认 180 毫秒，可在配置文件调整**；隐去后立即恢复点击穿透。
- **全局快捷键**：`Alt + Shift + Q`。窗口隐藏时唤出，唤出后保持可见约 2 秒（可配置），之后自动恢复隐身。
- **四档可调灰度字色**：四档灰度值可设为 0 ~ 255 之间任意值，保存后自动按白到黑排序；顶栏 `+` 循环切换并自动记忆。文字不加描边、光晕或阴影。
- **不透明度可调**：显现时整窗不透明度可在 0.15 ~ 1 之间调，想让字更淡、更融入背景都可以。
- **隐身开关**：顶栏 `/` / `\` 按钮，关闭隐身时窗口常显，便于调整位置与尺寸。
- **置顶开关**：顶栏 `>` / `<` 按钮，`>` 表示始终置顶（默认），`<` 表示普通窗口层级。
- **设置放在独立窗口**：不透明度、静止门槛、顶栏按钮、四档字色都在设置窗口里改，改完立即生效，主窗口一个按钮都不增加。
- **阅读位置记忆**：自动记录每篇笔记的滚动位置，再次打开回到原处，退出前会先保存。
- **文件列表**：顶栏 `≡` 或 `Ctrl + P`。打开列表时正文完全隐藏，屏幕上只剩文件名，默认只筛当前目录，可按文件名关键字筛选。
- **拖拽打开**：把文件夹或 `.md` 文件拖到程序或桌面快捷方式上即可，无需先启动。
- **纯只读**：程序不存在任何写入笔记文件的代码路径，笔记不会被修改、移动或删除。
- **免安装**：构建产物是一个可整体拷贝的绿色目录。

## 📥 下载安装

从 [Releases](../../releases/latest) 下载 `Chameleon.zip`，解压到任意位置，双击 `Chameleon.exe`。

- 免安装、免管理员权限，可放进 U 盘随身携带。
- 程序未签名，首次运行时 Windows SmartScreen 可能提示 → 点「更多信息」→「仍要运行」。
- 首次启动没有笔记：把笔记文件夹或单个 `.md` 文件**拖到 `Chameleon.exe` 上**即可打开。

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（x64） |
| 运行时 | 无需安装，Electron 已打包在内 |
| 解压后体积 | 约 270 MB |

## ⌨️ 快捷键

| 操作 | 效果 |
| --- | --- |
| 鼠标在窗口内完全静止（默认 0.6 秒，可调） | 淡入显现，可滚动、可选中文本 |
| 鼠标掠过窗口或仍在移动 | 不显示 |
| 鼠标移出窗口 | 淡出至不可见，恢复点击穿透 |
| `Alt + Shift + Q` | 唤出 / 隐藏窗口 |
| `Ctrl + P` | 打开 / 关闭文件列表 |
| `Esc` | 列表打开时关闭列表，否则隐藏窗口 |
| `Ctrl + +` / `Ctrl + -` / `Ctrl + 0` | 正文字号放大 / 缩小 / 复位 |

窗口无边框，四边与四角都能拖拽缩放（最小 120 × 80），顶栏中间区域可拖动窗口。

## ⚙️ 设置

设置放在**独立窗口**里，主窗口因此不会多出任何按钮。打开方式（任选）：

- 桌面「Chameleon Settings」快捷方式（构建时自动创建）；
- 命令行 `Chameleon.exe --settings`。

| 设置 | 说明 | 范围 |
| --- | --- | --- |
| 不透明度 | 显现时窗口整体的不透明度 | 0.15 ~ 1 |
| 静止显现门槛 | 鼠标需完全静止多久才显现 | 250 ~ 2000 毫秒（默认 600） |
| 顶栏按钮 | 勾选显示与否、按住行上下拖动排序 | — |
| 文字颜色 | 四档灰度（0 黑 ~ 255 白），自动按白到黑排序 | — |

顶栏里 `≡`（文件列表）固定最左、`×`（退出）固定最右且不可隐藏；中间四个可勾选、可排序。**勾选只控制显隐，行的位置不动**，顺序只能靠拖动改。

## 🎨 配置文件

配置文件位于 `%APPDATA%\chameleon\config.json`，采用「临时文件 + 重命名」原子写入。程序运行时会监听该文件，手改保存后立即生效；所有值写入前都会校验，写错也只会被钳制到合法范围，不会把窗口调成看不见。

| 字段 | 说明 |
| --- | --- |
| `notesDir` | 笔记文件夹的绝对路径 |
| `hotkey` | 全局快捷键，默认 `Alt+Shift+Q` |
| `ink` / `inkTones` | 当前字色序号 / 四档灰度值（0 黑 ~ 255 白） |
| `hoverOpacity` | 显现时的窗口不透明度（0.15 ~ 1） |
| `tools` / `toolsOff` | 顶栏按钮的排列顺序 / 隐藏列表 |
| `lastNote` / `scroll` / `zoom` | 上次打开的笔记 / 每篇的阅读位置 / 字号倍率 |
| `stillMs` / `fadeMs` / `revealMs` | 静止门槛（默认 600）/ 淡入淡出时长（默认 180）/ 快捷键唤出后保持时长（默认 2000），单位毫秒 |

例：让顶栏只留「文件列表 / 置顶 / 隐身 / 退出」

```json
"tools": ["files", "pin", "stealth", "ink", "hide", "quit"],
"toolsOff": ["ink", "hide"]
```

## 🛠 从源码运行与构建

需要 Windows + Node.js 20。

```powershell
git clone https://github.com/McQueen979/chameleon.git
cd chameleon

# 国内网络下 Electron 二进制需要镜像
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm install

npm start          # 正常运行
npm run dev        # 开发模式：打开开发者工具并输出运行自检日志
npm run build      # 构建免安装版
```

`npm run build` **完全离线**：直接使用 `node_modules` 里已下载的 Electron 运行时拼装，不下载 electron-builder / NSIS 等构建工具。产物是 `dist\Chameleon\`（约 270 MB），并自动在桌面创建「Chameleon」与「Chameleon Settings」两个快捷方式。

## 🧩 Markdown 支持

- 标准语法：标题、列表、引用、代码块、表格、分隔线。
- 笔记之间的相对链接可在窗口内直接跳转，`http(s)` 链接交给系统浏览器。
- 原始 HTML 标签按文本显示，裸 URL 不会自动变成链接，任务列表 `- [ ]` 按普通文本处理。
- 出于最小暴露面考虑，窗口禁止一切外部资源请求，因此笔记内的图片不会加载，正文文字不受影响。
- 渲染有兜底：单篇笔记里个别语法或路径处理出错时会降级为纯文本，绝不会因为一处内容导致整篇空白。

## ⚠️ 已知限制

- 仅提供 Windows 构建脚本，且为纯只读，不提供编辑功能。
- 仅识别 `.md` 与 `.markdown` 文件。
- 文件列表每次打开扫描一次目录，不持续监听变化；只支持按文件名筛选，没有全文搜索。
- 笔记文件夹需改配置文件切换，程序内没有切换入口。
- 字色需按背景手动切换（四档可调灰度），不采样下层画面颜色、不做自动适配。
- 顶栏符号不可自定义：`>` / `<`、`/` `\` 同时兼任状态显示。
- 阅读位置按滚动像素记录，调整字号后再次打开可能有少量偏移。
- 全局快捷键被其它程序占用时，改用再次双击程序唤出窗口。
